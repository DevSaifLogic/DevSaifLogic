# hey, i'm saif (DevSaifLogic) 👋

i'm a 17-year-old **logic architect & full-stack automation engineer**. 

my tech journey started back in 2015 on a terrible old laptop. i used to constantly break my windows OS and have to fix it myself by watching random youtube videos, all just to squeeze out extra FPS to make roblox run faster. that taught me exactly how operating systems and hardware handle resources under the hood.

ever since AI tools dropped, i stopped wasting time trying to memorize raw syntax and started operating as a pure systems architect. i use my logical thinking to map out exactly how data needs to flow, and then use AI as my execution layer to write clean code in whatever language fits the job (Python, Java, JavaScript, HTML). if a process can be optimized, automated, or connected over a network, i can build it.

### 🧱 featured projects

#### 📡 LAN & Hardware Utilities (Client-Server Automation)
*   **[laptop-specs-client](https://github.com) & [server](https://github.com)** – a dual-part system. the python client grabs local windows hardware specs and shoots them over the network to a central node.js server that logs everything into a local JSON database.
*   **[lan-barcode-scanner](https://github.com)** – scans a barcode using a phone camera and instantly types its value directly into the host PC over the local network.
*   **[camera-clipboard-paster](https://github.com)** – captures an image from a phone browser and automatically drops it straight onto the host computer's clipboard.

#### 🕹️ Minecraft Client Utilities (Fabric Mods)
*   **[litematica-auto-swap](https://github.com)** – a custom fabric mod that scans the block you are targeting in a litematica schematic and automatically swaps your active inventory item to match it.
*   **[lag-monitor](https://github.com)** – a client-side mod that monitors inbound network packet timing and flags exact packet data repetition to diagnose connection spikes.

#### ⚡ Workflow & Desktop Automations
*   **[flow-optima-queue](https://github.com)** – a real-time, mobile-first queue management app for teachers/students featuring live position tracking, lost-focus detection, and Bcrypt security.
*   **[youtube-chat-monitor](https://github.com)** – a desktop python utility that listens to live youtube streams for specific keywords and drops instant desktop alerts.
*   **[audio-timestamp-marker](https://github.com)** – a python app that lets you hit the spacebar while listening to media to instantly log and export SRT subtitle timestamps.
*   **[point-of-sale](https://github.com)** – a lightweight, local web dashboard prototype for managing store inventory, quick orders, and sales workflows.
